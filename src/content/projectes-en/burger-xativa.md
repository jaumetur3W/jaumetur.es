## A Complete Ordering Flow for a Concept Brand

Burger Xàtiva is a portfolio concept showcase rather than a live operating restaurant. The brand, menu, prices, food photography, and local data are designed for illustrative purposes. The application clearly identifies itself as an interactive demo.

The project demonstrates a seamless mobile-first experience for browsing a digital menu, customizing dishes, and navigating the common interaction screens of modern hospitality platforms.

## Key Features Explored in the Demo

- **Categorized Digital Menu & Cart:** Browse products with photos, descriptions, and dynamic price totals.
- **Interactive Burger Customizer:** Select cooking preferences, artisanal buns, and optional gourmet toppings with real-time price updates.
- **Simulated Delivery Tracker:** Displays realistic stages (Order Received, In the Kitchen, Out for Delivery) with an illustrative tracking code.
- **Table Reservation & VIP Club:** Accessible forms that validate inputs and return instantaneous UI feedback without persisting private data.
- **Conceptual Loyalty Reward:** A visual celebration trigger when orders reach five items, demonstrating gamification mechanics.
- **QR Menu Access:** Ready-to-scan QR code interface for fast in-venue ordering.

## Architecture & Technology

The site is built with Astro, compiling to lightweight static HTML with styles handled by Tailwind CSS and client-side interactivity managed by lean, dependency-free vanilla JavaScript modules. Zero heavy frameworks or slow backend databases are required for the client demonstration.

## Limits & Verification

All interactive states have been verified on mobile and desktop viewports. The application is completely honest with visitors, clearly indicating that order tracking, table booking, and customer reviews are prototypes for client review.
